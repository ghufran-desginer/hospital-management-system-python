🚀 المميزات التقنية (Features)

•	تطبيق مفاهيم OOP: بناء الكود بمرونة وتسهيل التوسع عبر (Classes, Inheritance, Encapsulation).
•	إدارة بيانات الأطباء والمرضى: تسجيل بيانات الأطباء والتخصصات، وتفاصيل إقامة وسجلات المرضى الطبية.
•	التحقق من صحة البيانات (Data Validation): معالجة الأخطاء أثناء التشغيل لمنع الإدخالات الخاطئة.
•	واجهة تفاعلية (Interactive CLI): قوائم تفاعلية في سطر الأوامر للإضافة، التعديل، العرض.

🛠️ التقنيات المستخدمة (Tech Stack)
